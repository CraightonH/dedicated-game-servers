# Valheim Dedicated Server

> ⚠️ Coming soon!

Valheim support will be added in a future release.

## Expected Features

- Valheim dedicated server deployment
- World persistence
- Password protection
- BepInEx mod support (optional)

## Interested in Contributing?

Follow the pattern from `games/factorio/` to add Valheim support:

1. Create `values.yaml` with Valheim-specific settings
2. Document configuration options in this README
3. Test deployment
4. Submit a PR!
