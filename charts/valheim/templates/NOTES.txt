📋 Useful Commands:

  View logs:
    kubectl logs -f -l app={{ .Values.name }}

  Watch server startup:
    kubectl logs -f -l app={{ .Values.name }} | grep -E "Game server|DungeonDB"

  Backup world saves:
    POD=$(kubectl get pod -l app={{ .Values.name }} -o jsonpath='{.items[0].metadata.name}')
    kubectl cp $POD:{{ .Values.persistence.mountPath }}/worlds ./valheim-backup

  Restart server:
    kubectl delete pod -l app={{ .Values.name }}

  Check automatic backups:
    POD=$(kubectl get pod -l app={{ .Values.name }} -o jsonpath='{.items[0].metadata.name}')
    kubectl exec $POD -- ls -lh {{ .Values.persistence.mountPath }}/backups

⚙️ Configuration:

  The server will:
  - Check for updates every 15 minutes (when idle)
  - Restart daily at 5 AM (when idle)
  - Create hourly backups (kept for 3 days)

  To change settings, update your values.yaml and run:
    helm upgrade {{ .Release.Name }} {{ .Chart.Name }} -f values.yaml

🎮 Playing:

  First-time players:
  - Create a new character when you join
  - The world will be automatically created if it doesn't exist
  - Your character is saved server-side

  Existing worlds:
  - Copy your .db and .fwl files from Windows:
    C:\Users\<username>\AppData\LocalLow\IronGate\Valheim\worlds\
  - To the server:
    kubectl cp <worldname>.db <pod>:/config/worlds/
    kubectl cp <worldname>.fwl <pod>:/config/worlds/
